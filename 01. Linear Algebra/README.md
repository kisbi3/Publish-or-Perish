# Linear Algebra

- **주교재:** Friedberg, Linear Algebra
- **주요 내용:** 벡터공간, 선형변환, 고윳값과 고유벡터, 스펙트럼 정리, SVD, 조르당 표준형
- **일정:** 고정 기간 및 주차별 분량 없음
- **진행:** 미팅(Session)마다 두 사람이 각각 발표하며, 발표자당 1~2 Chapter를 기본으로 필요시 조정
