- **주요 내용:** Scaling, universality, percolation, self-organized criticality
- **일정:** 고정 기간 및 주차별 분량 없음
- **진행:** 세션당 한 명 발표, 1~2 Chapter를 기본으로 필요시 조정

## Sessions
